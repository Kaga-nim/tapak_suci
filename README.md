# 🥋 Website Ekskul Tapak Suci — Universitas Pamulang

Website profil resmi Ekstrakurikuler Tapak Suci Universitas Pamulang (UNPAM), dibangun sebagai kontribusi untuk ekskul Pencak Silat Muhammadiyah yang telah mencetak banyak atlet berprestasi.

🌐 **Live Demo:** [tapak-suci-unpam.vercel.app](https://tapak-suci-unpam.vercel.app) *(update setelah deploy)*

---

## ✨ Fitur

- **Sidebar Navigasi Responsif** — Collapse otomatis di desktop, hamburger menu di mobile
- **Galeri Kegiatan + Lightbox** — Filter per kategori (Latihan, Event, Prestasi) dengan preview gambar full-screen
- **Animasi Counter** — Statistik ekskul yang animasi saat di-scroll ke bagian Prestasi
- **Mobile Friendly** — Tampilan optimal di semua ukuran layar (HP, tablet, desktop)
- **Lazy Loading Gambar** — Gambar hanya dimuat saat muncul di layar, halaman lebih ringan
- **Integrasi WhatsApp** — Tombol pendaftaran langsung terhubung ke WhatsApp pelatih

---

## 🛠️ Teknologi

- HTML5, CSS3 (vanilla — tanpa framework)
- JavaScript ES6+ (vanilla — tanpa library)
- [Font Awesome 6](https://fontawesome.com/) — ikon
- [Google Fonts](https://fonts.google.com/) — Poppins & Roboto

> Project ini sengaja dibuat tanpa framework/build tool agar ringan dan mudah di-maintain oleh siapa saja.

## 🚀 Cara Menjalankan Lokal

Tidak perlu instalasi apapun. Cukup buka `index.html` langsung di browser, atau gunakan ekstensi **Live Server** di VS Code untuk hasil terbaik.

---

## ☁️ Deploy ke Vercel

1. Push repo ini ke GitHub
2. Buka [vercel.com](https://vercel.com) → **Add New Project** → import repo
3. Framework Preset: pilih **Other**
4. Klik **Deploy**

Cache gambar sudah dikonfigurasi otomatis via `vercel.json` (1 tahun).
